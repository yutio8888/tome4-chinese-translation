## 3. 词源假说与排除（本文主要价值）

2026-09-20 由三个模型（`codex/gpt-6-astra` high、`claude/claude-opus-5` medium、`grok/grok-4.6`）**各自独立**评估以下路径，随后汇总。记录于此以防日后重复讨论。

| # | 假说 | 音/义契合 | 外部佐证 | 裁定 |
|---|---|---|---|---|
| A | 梵语 शान्ति *śānti*「和平、寂静」 | 音近；**义反** | 无 | **排除** |
| B | 亚美尼亚语 շանթ *šantʻ*「闪电」 | 音、义俱贴 | 无 | **排除** |
| C | 波斯语 شاندیز *Shandiz*（地名） | 音更近；义无关 | 无 | **排除** |
| D | 希伯来语 *shatnez* | 仅形近 | 无 | **排除** |
| E | 托尔金语（辛达林／昆雅） | 音系不容 | — | **近乎可排除** |
| F | 艾略特《荒原》末章的梵语收束词 | 同源于 A | 无 | **排除**（提出者自行否决） |

**逐条理由：**

- **A（*śānti*）**：这是 shanti 一词唯一广为人知的实词来源，因此必须处理。但语义（和平、寂静）与一把雷暴匕首正相反；且 ToME4 项目内**不存在印度语系命名传统**，缺少建立该路径的先例。判为音形巧合。
- **B（շանթ）**：三模型中语义契合度最高的一条——音近且义为「闪电」，与物品效果完全对应。**但完全没有佐证**：无设计文档、无论坛帖、无提交信息提及。若采信，等于凭音义巧合反推作者意图。按「不得添加未经核实的词源主张」原则排除。**此条是最容易被日后重新提出的假说，记录在此以明确其已被评估并因缺证而排除。**
- **C（Shandiz）**：音形最近（`Shan-` + 齿音），但波斯地名与雷暴、匕首均无语义联系，且无任何使用痕迹。
- **D（shatnez）**：希伯来语中指混纺织物的宗教禁忌，与本物品无任何语义交集，仅字母序列形近。
- **E（托尔金）**：ToME 世系与托尔金有渊源，故需检查。辛达林与昆雅音系**不允许词末 `-z`**，且 `sh` 仅见于黑语。结构上不成立。
- **F（《荒原》末章）**：由 `claude/claude-opus-5` 提出——该诗末章（"What the Thunder Said"）以重复的梵语收束词结尾，章节标题与「雷」相关，表面上似有关联。**提出者当场自行标注为巧合级联想并明确声明不作依据**：其收束词即假说 A 的同一个梵语词，语义同样是「和平」，且该联想需要作者同时具备文学引用意图与语义反转意图，无任何证据支持。**本条被提出并被排除，如实记录以免日后有人重新提出。**

### 3.1 三方收敛结论

> **`Shantiz` 无可考词源，是 2014-01-04 替换 WoW 专名 `Al'akir` 时现造（coined）的名字。**

三模型在此结论上**无分歧**。分歧仅出现在译名候选（见 §4.3）。

## 4. 译名裁决

### 4.1 库内 Sh- 音译先例（已核实）

```
grep -ohE 't\("[^"]*Shandral[^"]*", "[^"]*"' *.lua
```

| 英文 | 现译 | 对应音节 |
|---|---|---|
| `Shatur` | 夏特尔 | Sha- |
| `Sher'Tul` | 夏·图尔 | Sher- |
| `Shax` | 夏克斯 | Sha- |
| `Shasshhiy'Kaish` | 莎西·凯希 | Sha- |
| **`Shandral`** | **珊**德拉 | **Shan-** |
| `Shivgoroth` | 西弗格罗斯 | Shi- |

**关键判据**：「夏」对应的一律是 Sha-/Sher-（开音节），而闭音节 **`Shan-` 在库内已有专属先例 `Shandral`→珊德拉**。因此本条应走「珊」而非「夏」。

### 4.2 双向冲突检查（已核实）

- 三个候选 `珊提兹` / `珊蒂兹` / `杉提兹` 在全库 **0 占用**（未被任何其它英文词占据）；
- 「珊」字现有用法仅两处族群：`coral`→珊瑚、`Shandral`→珊德拉。两者均不与本条目构成歧义。

### 4.3 三方分歧与收敛

| 模型 | 首选 | 理由 |
|---|---|---|
| `codex/gpt-6-astra` | 珊**蒂**兹 | 音节更贴 `-tiz` |
| `claude/claude-opus-5` | 珊**提**兹 | 「蒂」女性色彩偏重，神器匕首不宜 |
| `grok/grok-4.6` | 珊**提**兹 | 同上（独立给出） |

分歧点仅在第二字 `蒂` vs `提`。opus-5 与 grok **各自独立**给出同一否决理由：「蒂」在中文译名语料中女性色彩偏重，用于一把神器匕首不合适。astra 的首选未提出反驳该点的论据。

### 4.4 裁定

> **维护者裁定（2026-09-20）：`Shantiz` → 珊提兹。已批准。**

## 5. 现存缺陷与待落地改动

### 5.1 现状

```
mod-tome.lua:13198  t("Shantiz the Stormblade",                      "风暴之刃",               "entity name")
mod-tome.lua:13199  t("thin stormy blade",                           "细长的风暴之刃",          "_t")
mod-tome.lua:13202  t("#GREEN#Shantiz strikes down a projectile!",   "#GREEN#风暴之刃击落了抛射物！", "logPlayer")
```

### 5.2 缺陷一：丢专名

`X the Y` 形式的专名，库内主流构式为「修饰语 + 音译名」，不加「的」：

隐居者亚格雷姆利、毁灭者高尔布格、弑龙者马萨克、天灾巨龙库洛塔、泰坦座狼郎格夫、收割者布罗托克、独角者纳克托什、竞技场主宰瑞吉。

维护者实测：库内 31 条中 30 条保留音译人名（96.8%），**本条是唯一孤例**。

本次独立复核（窄口径正则，限 `"entity name"` 类型且第二段首字母大写）：

```
grep -ohE 't\("[A-Z][A-Za-z'"'"'.]+ the [A-Z][A-Za-z ]+", "[^"]*", "entity name"\)' *.lua | sort -u
```

命中 26 条，其中 25 条保留音译人名，唯一例外即 `Shantiz the Stormblade`。口径比维护者的窄（漏掉若干含撇号／非 `entity name` 类型的条目），故计数不同，**但结论方向一致**。

### 5.3 缺陷二：unided_name 剧透

13199 把鉴定后的正式名整块复现进未鉴定名（`细长的风暴之刃` 内含 `风暴之刃`），玩家**未鉴定即可看到正式名**，鉴定机制失效。

英文原文两者是分得开的：`thin stormy blade` 是「形容词 + 普通名词」的泛指描述，`Stormblade` 是复合专名。中文亦应分开。

### 5.4 改动清单

| 行 | 现译 | 拟改 | 状态 |
|---|---|---|---|
| 13198 | 风暴之刃 | **风暴之刃珊提兹** | 已批准（方案 A，库内主流构式） |
| 13199 | 细长的风暴之刃 | **细长的风暴刀刃** | 已批准。与正式名的「风暴之刃」错开一字，保留源串 `thin stormy blade` 的朴素描述语域 |
| 13202 | #GREEN#风暴之刃击落了抛射物！ | #GREEN#珊提兹击落了抛射物！ | 原文此处仅出现 `Shantiz`，随 13198 一并裁定 |

**13198 候选（待裁）**

- **A. 风暴之刃珊提兹** —— 严格套用库内主流构式（修饰语 + 音译名，不加「的」），与 隐居者亚格雷姆利 同型。
- **B. 风暴之刃·珊提兹** —— 加间隔号，可读性更好，但库内 `X the Y` 条目少见此写法（`格尔格勒克·黑暗吞噬者` 用的是逗号／间隔号且语序相反）。
- 不建议保留现状「风暴之刃」（丢专名），亦不建议「珊提兹的风暴之刃」（改变了原文的同位语结构，且与库内构式不符）。

**13199 候选（待裁）**

约束：**不得整块包含 13198 的正式名**，否则剧透依旧。

- **A. 细长的风暴匕首** —— 与 `thin` / `blade`（匕首本体）都对得上，且不含「风暴之刃」四字连串。
- **B. 细长的雷暴短刃** —— 换用「雷暴」避开「风暴」字面，与物品的闪电效果相符；但离原文 `stormy` 略远。
- **C. 纤细的暴风之刃** —— 保留「之刃」语感，靠调换「风暴/暴风」避开正式名；规避较弱，若 13198 最终定为 B 型带间隔号的写法，重合风险仍在。

> 三项改动**不得在本文档中自行落地**；`Shantiz`→珊提兹 之外的部分需维护者裁定后，由后续修复批统一执行。
