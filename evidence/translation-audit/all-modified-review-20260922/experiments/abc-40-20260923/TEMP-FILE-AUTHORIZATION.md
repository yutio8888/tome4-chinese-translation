# 用户追加：临时文件允许

用户明确指示：“后续实验允许写入临时文件”。该指示优先于冻结旧prompt中的无例外不写文件要求，适用于之后派发的实验角色。

允许在仓库外任务专属临时目录（例如/tmp/abc40-<dispatch>/）或本任务忽略的.artifacts临时目录保存/删除中间文件；不得写入译文、术语、冻结输入、其他task、生产queue/catalog，不得读取别人的临时材料。临时文件不能成为未审计的额外输入来源。实际读取范围和数据版本约束不变。

历史记录不追溯改写；以先前规则隔离的报告仍保留其当时判定及理由。内容准确性诊断独立于流程合规，后续不因正常临时文件使用判废或重跑。
