# 原判定保留与非标准claim标签

Opus将C03、C07、C10、C16标为“上游误述（不计为译文缺陷）”，将C11标为“未发现问题（偏离英文，但与源码一致）”。这些观察均保留原文进入匿名裁决，不因标题不在三种问题标签内而漏提取。

四项明确不列为缺陷的原断言记为NON_DEFECT，C11记为OK；即使裁决后来确认缺陷，也不追算为原本明确报错检出。三臂统一输入要求分别处理上游和译文新增问题，模型擅自豁免上游的判断差异留给内容计分，不通过重跑删除。

host提取器仅扩展标题识别，保留原始标题original_label及报告offset/hash；未改变冻结prompt、条目判定或claim内容。
