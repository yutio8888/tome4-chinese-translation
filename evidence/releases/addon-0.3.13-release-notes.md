## 0.3.13

- 译文 13,819 条（核心 8,169，引擎 189，DLC 5,461）。
- **技能撞名改名**：11 组技能原本由不同技能共用同一个中文名，现在每组只有一个技能保留原名，其余改用新名：

  | 英文 | 新名 | 保留原名的技能 |
  | --- | --- | --- |
  | Realign | 身心调谐 | Re-assemble（重组） |
  | Reform | 重聚成形 | Re-assemble（重组） |
  | Rethread | 重编时间线 | Re-assemble（重组） |
  | Quake | 震地猛击 | Earthquake（地震） |
  | Brutality | 狂暴虐杀 | Pitiless（无情） |
  | Eldritch Infusion | 秘法灌注 | Arcane Feed（奥术充能） |
  | Dual Arrows | 双箭齐发 | Double Shots（双重射击） |
  | Mow Down | 绞肉收割 | Dismember（肢解） |
  | Resolve | 抗逆决意 | Unbreakable Will（坚定意志） |
  | Swift Shot | 疾风投射 | Quick Shot（快速射击） |
  | Quickened | 思维加速 | Celerity（迅捷） |
  | Smokescreen / Smokescreen Mastery | 烟幕障眼 / 烟幕障眼精通 | Smoke Bomb（烟雾弹） |
  | Terrorize | 恐吓震慑 | Mortal Terror（致命恐惧） |

  技能自带的效果名、伤害类型，以及其他说明里提到这些技能的地方都已同步。NPC 技能 Deadly Strikes 改为「致命破击」，与玩家技能 Death Blow（致命打击）区分开。
- **说明文字更正**：
  - 危机感知：补上「可以豁免的」负面效果这一限定。危机感知、解除陷阱的「侦测强度」叫法统一。
  - 利牙项环：补出「脖子的断口」。
  - 生命线编织：改正是哪一项数值随法术强度提升。
  - 身心调谐：补上数量词。
- **显示与格式**：
  - 配件制造界面「状态」列改为「可制作 N 级」，避免等级数字被截断。
  - 若干「标签：数值」去掉冒号后多余的空格，涉及成就进度、用户信息、升级窗口的当前/初始技能等级等。
  - 「区域效果：」格式统一。
  - Embers 任务中「H.C. 帕默」改为「阴霾指挥官帕默」，GEM 统一为「G.E.M.」。
  - 便携式自动材料提取仪的正文不再残留 APE。
- 插件代码与 0.3.12 相同。

安装：下载 `tome-chn-mod.teaa` 放入 `game/addons/`，删除旧版后在游戏 addons 菜单启用 chn-mod，语言选简体中文。

## 发布后验收（请测试玩家帮忙）

本版本发布前完成的是技术核对：版本与来源身份、完整自动检查、运行时条目核对（0 缺失/不符）、加载冒烟测试、安装包结构与哈希。**本版本没有在游戏中做过完整验收，实机验收由测试玩家在发布后进行。**

此前的本地测试都是在**公开版 0.3.12** 上用调试菜单到场、生成物品后查看界面，不是 0.3.13 的全场景实测。本版新改的文字都还没有在游戏中看到过。请在正常游戏中留意：

1. **改名后的技能**：在技能界面、升级窗口、快捷栏、效果提示和战斗日志中，上表技能应显示新名。同一屏里不应再出现两个不同技能同名的情况。
2. **配件制造界面**（Embers）：「状态」列应完整显示「可制作 N 级」，能看到等级数字。
3. **升级窗口**：未学习的技能，标题应为「初始技能等级：1」；已学习的应为「当前技能等级：N」，冒号后没有多余空格。
4. **危机感知、利牙项环、生命线编织、身心调谐**的说明文字。
5. **Embers 任务对话**中的「阴霾指挥官帕默」和「G.E.M.」。

此前调试测试中尚未覆盖的场景（仍欢迎反馈）：
- 托马克的另外 2 条技能；
- 艾格尼尔的攻击/防御页；
- 沃尔的属性/装备页及其余技能；
- 半神效果图标；
- 水晶球的激活界面；
- 其余配件配方的说明。
