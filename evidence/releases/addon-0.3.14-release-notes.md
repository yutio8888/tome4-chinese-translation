## 0.3.14

- 译文 13,831 条（核心 8,181，引擎 189，DLC 5,461）。
- **插件代码更新（动态数值说明修正，`3580885`）**：
  - **血流（Bloodstream，Embers）**：中文技能说明改用插件专用补充键，代入游戏实际生效的流血倍率（`getDamage`），并写明触发条件（攻击命中且目标攻击前已在流血、命中后流血仍在，每项流血最多强化一次）。上游原键中文保持与 `getDamageInc` 对应的「伤害增加 %d%%」契约，确保任意代码/旧译文组合或异常回退时不会出现措辞与数值错配。
  - **自动修复系统（Automated Repair System，Embers）**：中文效果说明改从临时数值表读取实际的生命回复、全抗性与死亡阈值增量，不再误读被激活过程覆盖的临时值 ID。
- **剩余技能与效果撞名改名**：补全 0.3.13 之后剩余 10 组技能撞名与 1 组 Cults 效果撞名（酸液喷吐、毒性喷吐维持不变；Embers 人物 Clork 按官方多数用法保留「克拉克」）：

  | 英文 | 新名 | 保留原名的技能/效果 |
  | --- | --- | --- |
  | Flamespit（召唤物） | 火焰喷吐 | Flame Jet（火焰喷射） |
  | Incendiary Ammunition | 燃烧弹药 | Incendiary Shell（燃烧弹） |
  | Ice Bolt（NPC） | 寒冰飞矢 | Ice Shards（寒冰箭） |
  | Corrosive Vapour（NPC） | 腐蚀酸汽 | Corrosive Mist（腐蚀酸雾） |
  | Overpower（NPC） | 强力压倒 | Dominate（压制） |
  | Flare Shell | 闪光炮弹 | Flare（闪光弹） |
  | Speed Sap（NPC） | 速度汲取 | Slow（减速） |
  | Mitotic Split（召唤物） | 受创裂变 | Mitosis（有丝分裂） |
  | Restoration（NPC） | 自然复原 | Nature's Touch / 自然治愈 |
  | Rocket Pod | 火箭巢 | Rocket Launcher（火箭发射器） |
  | Persistant Will（Cults 效果） | 偏执意念 | Unbreakable Will（坚定意志） |

  上述技能的自带描述、效果、锁定提示与战斗日志均已同步。
- **潜行/隐形与陷阱侦测术语统一**：
  - 带数值的 `see_stealth` / `see_invisible` 统一对齐角色面板标签「侦测潜行」「侦测隐形」（涵盖侦测圣歌、感知、预知时刻、感知增强、星界投射、显影护目镜、感知潜行效果、阳光照耀等）。
  - 「侦测强度」专用于陷阱侦测（`see_traps`，对齐危机感知、解除陷阱、感知增强）。
- **技能条件链与说明语义修正**（覆盖两轮随机抽检、换行差异族与 343 条技能条件链候选池全部清零）：
  - **按实现校对条件链与数值**：
    - 炽热献祭（Burning Sacrifice）：击杀非燃烧目标同样触发 5 回合冷却；
    - 焚烧打击（Incinerating Blows）：基础灼烧与爆燃判定均需近战命中；
    - 皮下金属化（Subcutaneous Metallisation）：持续时间由 6 回合更正为 5 回合；
    - 脱离相位（Out of Phase）：区分 40 点固定闪避上限与 40% 抗性/持续时间上限；
    - 触手地狱（Tendrils Eruption）：区域内所有敌人无论是否被触手命中都需进行麻木检定；
    - 恶魔契约（Demonic Pact）：视野外相位门改为在最大范围内随机传送而非失效；
    - 体内触手（Inner Tentacles）：仅在消化状态下生效；
    - 低温掘进（Cryogenic Digs）：补回护盾被击破的触发条件；
    - 寄生水蛭（Parasitic Leeches）：吸取周期并非固定间隔；
    - 尸体爆炸（Corpse Explosion）：明确每回合最多引爆 1 只最早召唤的食尸鬼，受伤害或死亡均可触发；
    - 暗影帷幕（Shadow Veil）：明确以首次攻击落点为中心计算范围，无有效目标时提前结束；
    - 疯狂诅咒（Curse of Madness）：补回「造成的伤害」并对齐 ≥ 最大生命阈值；
    - 严酷决心（Grim Resolve）为移除毒素/疾病而非抗性、净化纹身明确持续时间增长对象、误导明确检定失败后转移。
  - **措辞与格式修正**：
    - 寒冰飞矢伤害类型改为寒冰伤害；潜行「潜行点数」→「潜行强度」；陷坑陷阱「暂时移出游戏」→「暂时移出战斗」；
    - 重力陷阱拉扯概率、钝击射击起止对象、腐蚀蠕虫「蠕虫团」→「蠕虫」、尸体诅咒半角逗号统一全角并理顺 4+ 级措辞；
    - 岩石尖刺片段逗号与多处换行/段落结构对齐（五灵挥击、驱散、冰爪、暗影烈焰、无赖、蜘蛛机器人等）。

安装：下载 `tome-chn-mod.teaa` 放入 `game/addons/`，删除旧版后在游戏 addons 菜单启用 chn-mod，语言选简体中文。

## 发布后验收（请测试玩家帮忙）

本版本发布前完成的是技术核对：版本与来源身份、完整自动检查（17 项 CI 门禁全部通过）、运行时条目核对（0 缺失/不符）、加载冒烟测试、动态说明修复单元测试（132 项，使用测试桩数值，未在实机运行）、安装包结构与哈希。**本版本没有在游戏中做过实机验收，实机验收由测试玩家在发布后进行。**

此前的本地实机测试都是在**公开版 0.3.12** 上用调试菜单到场、生成物品后查看界面，不是 0.3.14 的实机覆盖。本版新增的插件挂钩与改动的文字都还没有在游戏中实际看到过。请在正常游戏中留意：

1. **血流（Bloodstream，Embers 链锯屠夫）**：查看技能说明中的流血倍率（应显示「伤害变为原来的 N%」而非旧的「伤害增加 N%」），并确认战斗中不会触发 Lua Error。
2. **自动修复系统（Automated Repair System，Embers）**：触发该状态后悬停查看效果图标说明，确认生命回复、全抗性、死亡阈值显示为正常增减数值（而非 1/2/3 类临时值 ID），且效果结束后属性恢复正常。
3. **新改名的技能与效果**：在技能界面、升级窗口、配件/物品列表、效果提示与日志中核对上表 11 项（如火箭巢、闪光炮弹、偏执意念等），确认无重复撞名或残留旧名。
4. **侦测潜行 / 侦测隐形 / 侦测强度**：查看侦测圣歌、预知时刻、感知增强、星界投射、显影护目镜及感知潜行效果说明。
5. **条件链与说明修正**：暗影帷幕、尸体爆炸、脱离相位、皮下金属化、疯狂诅咒、尸体诅咒、炽热献祭、焚烧打击、触手地狱、低温掘进等技能说明。
