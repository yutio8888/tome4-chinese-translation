## 0.3.17

- 译文 13,821 条（核心 8,153，引擎 207，DLC 5,461；覆盖 `0569–0574` 共 6 批精修与全量门禁，完成面向中文老玩家社区习惯的全面专名/术语核对与回调，同时保留真正影响玩法理解的机制纠错）。
- **高频机制术语与铭文短描述优化（`0569–0571`）**：
  - **高频术语回调社区共识**：`全局速度` → **`整体速度`**（全库 73 处清零）、`暴击倍率` → **`暴击伤害`**（全库 8 处）、`CharacterSheet` `状态效果抗性：` → **`状态效果免疫：`**、`Nightmare` 难度 → **`梦魇`**、`Rune: Manasurge` → **`符文：法力风暴`**（保留 `Manaflow` = `法力涌动`）、职业名恢复 **`支配者`**（`Possessor`）、**`苦痛者`**（`Writhing One`）、**`枪手`**（`Gunslinger`），并按社区讨论保持 `Corruptor` = **`腐化者`**。
  - **铭文/刻印短描述精简（24 条）**：统一 `mod-tome` 与 `tome-orcs` 纹身/符文/污印/植入物括号短描述为紧凑原生措辞与半角 `; ` 分隔，并将 `taint` 铭文说明统一为 **`污印`**。
- **材质、故意错字风味与经典神器名称回调（`0572`）**：
  - **`stralite` 材质回调为 `蓝锆石`**（全库 73 处统一，同步彻底消灭历史错字“蓝皓石”）。
  - **还原格鲁什戈尔故意拼错风味**：`Dethzaw` → **`死忘链据`**、`Dethblyd` → **`死忘太剑`**。
  - **回调 15 组经典神器名称及直接引用**：`夏日之殇` / `夏殇`（历法月份保持 `炎华月` 不撞名）、`泰坦尼克`、`魔宗利刃`、`生命之心`、`众星之握`、`石化风衣`、`刺客契约`、`至尊法杖`、`魔爆碎片`、`鲍尔本的大门扣`、`战争之王格纳哥的饮血剑`、`乌瑞斯拉克的意志`、`冰霜巨人护手`、`暗黑礼服`、`三头龙之牙`。
- **觉醒技、地名、技能树、技能、Boss 与装备词缀回调（`0573–0574`）**：
  - **觉醒技（Prodigies）**：保留 **`心灵暴政`** 与 **`法术反馈`** 两项准确纠错，其余 8 项经典觉醒名回调为 **`自由格斗`**、**`和风守护`**、**`弧光之盾`**、**`奥术之握`**、**`战争践踏`**、**`化作星星吧！！`**、**`巨人之锤`**、**`纳鲁精灵的馈赠`**（同步骷髅王技能说明、成就与三叉戟实体）。
  - **经典地名**：回调 **`黑暗地窖`**（`Dark crypt`）、**`里奇虫巢`**（`Ritch Hive`）、**`乌瑞斯拉克沉睡处`**（`Ureslak's Host`）及对应入口/任务/成就。
  - **技能树与高频技能**：技能树回调 **`支配`**（支配者 DLC，保留 `Assume Form`/`Possess` = `附身`）、**`具象之弧`**（含全树技能与说明）、**`唯我主义`**、**`唯心主义`**、**`街头格斗`**、**`梦境锻造`**；技能及同名状态回调 **`特种训练`**、**`石化皮肤`**、**`湮灭洪流`**、**`时光凋零`**、**`烟雾弹`**、**`快速射击`**、**`矮人坚韧`**（`Dwarven Resilience`）。
  - **经典 Boss、职业统一与装备词缀**：Boss 回调 **`傀儡之王阿塔玛森`**、**`卡洛·斐济`**（跨本体及三大 DLC 0 残留）、**`代号“Z”`**（红帕兰实验日志保留 `实验体 A–Z` 语境）；将敌对 NPC `shadowblade` 与玩家职业统一为 **`影舞者`**；回调装备词缀 **`咒术师的` / `咒语之` / `星空咒术师`**、**`完美之`**、**`织岚的`**。

安装：下载 `tome-chn-mod.teaa` 放入 `game/addons/`，删除旧版后在游戏 addons 菜单启用 `chn-mod`，语言选简体中文。
