## 四、复核后判定「不报」的疑点（避免重复或误报）

- `zoom-electr`：静电射击「被电击的目标失去至多 N 个物理或精神增益效果」——源码 `tome-orcs/data/talents/steam/gunner-training.lua:139-148` 只移除 `type == "physical" or "mental"` 且 `status == "beneficial"` 的效果，译文比英文原文（non-magical effects）更准确，不报。
- 痛苦压制药剂「获得 N% 全体伤害抗性」——源码 `EFF_PAIN_SUPPRESSOR_SALVE` 是 `resists = {all=...}`，与译文一致，只报语序（r2-ds-03）。
- 「铁，思维」「铁，强化，火焰」这类主手/副手短名——由引擎把词缀关键字用「, 」拼接，非译文问题。
- 「护甲强度」（armour hardiness）、「手札」（lore）、「马基·埃亚尔」等既定译名全库一致，不报。
- 角色面板标签「暴击摆脱」（Crits Shrug Off）：tooltip 已解释为「按比例减少额外暴击伤害」，属可接受措辞，仅记 advisory。
- 「被切成葱花」（minced）为官方旧译的幽默处理，属风格选择，不报。
- 启动菜单、欢迎框、主菜单左侧面板、DLC 成就分类、对话立绘名牌等已知硬编码英文/官方旧译，按第一轮处置不再报。

1. r2-ds-09（鼠标贴图 → 自定义鼠标光标）：玩家最容易误解的选项名。
