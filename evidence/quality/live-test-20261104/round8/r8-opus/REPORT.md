## 核实过、不予报告的内容

- **太阳耀斑**、**灼热之矛**、**法阵四技能**、**圣诗专家**的数值行：与源码（sunlight.lua、circles.lua、hymns.lua）的占位符和数值一致。
- **纹身：野性**的「随机解除你身上的物理负面效果各一个」：拼接逻辑来自 concatNice，与源码相符；作为单一类型时读起来稍怪，但不算错。
- **「奥术之 (+N)铜戒指」类后缀加括号的顺序**（如「力量之 (+2)星光的铜项链」）：已有 advisory（r3-sonnet-07），不再重复报告。
- **护送任务日志「接受了任务“”！」**：r3-sonnet-05 已驳回，属上游时序问题。
- **「%s将这一效果的持续时间降低0回合」**：已知问题。
- **手札「这就是笔记 里提到的钥匙吗？」里看起来多出的空格**：是斜体换行渲染造成的，原文（mod-tome.lua:18676）没有空格。
- **「法杖掌握」和「法杖掌控」**：是两个不同的技能（Staff Mastery 和 Command Staff），不算不一致。
- **「护送失败」说明**：已经是修复后的「你未能保护好迷路的战士，白色蠕虫团杀死了对方。」，修复已生效。
