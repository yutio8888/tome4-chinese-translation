## 结论（问题统计）

- **新增问题：1 条**（`cls11b-c2-01`，format／minor）：装备提示框「有效值」串丢失源串空格，显示为「+2(+2有效值)」。
- 其余逐条核对未发现 fidelity／数值／条件／占位符／残留英文问题；多处译文与实现比对后确认比英文原文更贴合代码
  （断脊「持续 5 回合」「非精神类持续技能」、金属狂怒「每回合首次近战命中」、巨震引擎「除你以外」均与源码一致，
  对应英文串本身与实现有出入，不算译文缺陷）。
- 复核后**撤销**的疑似问题（记录备查，不提交）：
  - 「瓦·埃亚尔」＝Var'Eyal（`terminology/places.tsv` 已裁决），战役说明中与「马基·埃亚尔」并存属不同地名，非错译。
  - 「兽族忍耐」＝Hold the Ground 的意译，`.artifacts/i18n/continuation-20260922/review251-host-decisions.json` 已裁决不改。
  - 利齿护盾「24%，有…」看似「,，」双标点，放大后为引擎多级数值分隔符 ＋ 全角逗号，正常。
  - 低分辨率下曾误读「切臂」为「切膏」、「严重割伤」为「严重剧伤」、开场文本「直通克鲁克」为「克鲁克克」，
    放大核对均与译文库一致，未提交。
  - 治疗药剂提示框缺句号一行（「它可以用于治疗 109 点生命值」）与英文模板 `"It can be used to %s\n\nActivation puts %s on cooldown for %d turns."`
    一致（英文首句也无句号），非缺陷；「置入冷却状态15回合」不带空格与本库同类串（`mod-tome.lua:998`）写法一致，按风格不报。

1. 先在种族列表点开「兽人」父项（`[BIRTHER] set descriptor race nil`），右侧说明只显示战役文字、
