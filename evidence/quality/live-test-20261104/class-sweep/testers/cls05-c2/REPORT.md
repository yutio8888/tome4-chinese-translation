- 星月术士职业正文「…再召唤群星之怒」与技能树名「星怒」措辞不同：属行文与树名分工，非同一实体命名冲突，且前几轮已覆盖该类判定。

- 鉴定水晶球「类型：水晶球/水晶球」：源码 `type="orb", subtype="orb"`，属忠实呈现，非翻译问题。
- 装备位标签只有材质名（榆木/亚麻/黄铜）：来自 `short_name` 字段（官方旧译 `t("elm","榆木","entity short_name")`），非本库问题。
