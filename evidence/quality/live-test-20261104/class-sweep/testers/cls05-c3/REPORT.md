## 一、指定组合不可选（重要偏差，已按要求替换）

任务指定的 **职业 Empyreal（高天者，Embers）**在游戏中**不可选**，因此「高天者 + 食尸鬼」组合无法创建：

- 源码证据：`/workspace/tome4-dlcs/orcs/tome-orcs/data/birth/classes/empyreal.lua`
  - 第 20 行为注释：`-- getBirthDescriptor("class", "Celestial").descriptor_choices.subclass["Empyreal"] = "allow"`
  - 第 64 行为注释：`-- getBirthDescriptor("world", "Maj'Eyal").descriptor_choices.class.Empyreal = "allow"`
  - 基类 `Celestial`（`git show 624a67329fe2:game/modules/tome/data/birth/classes/celestial.lua`）的
    `descriptor_choices.subclass` 为 `__ALL__ = "disallow"`，仅允许 Sun Paladin / Anorithil。
- 实机证据：创建界面展开「天空系」只有「太阳骑士」「星月术士」（`shots/142437-celestial-open.png`）。
  即 Empyreal 是被禁用的内容（其技能树 sol/cosmic/energies/reflection/void 在库内有译文，但游戏内无法读到）。

**替换方案**：保留指定种族 **食尸鬼（Ghoul）**，职业改为 **链锯屠夫（Sawbutcher）**——Embers 的
「工匠系」职业（`worlds.lua:97` 允许其在主战役中使用），既保住 Embers 文本覆盖面，又避开本组
c1（太阳骑士/高等人类）、c2（星月术士/半身人）已覆盖的天空系。
角色：`CLS053`，食尸鬼 链锯屠夫，战役「马姬·埃亚尔的传说」（马基·埃亚尔：卓越纪），难度「简单」，死亡模式「冒险模式」。
起始区域：荒芜废墟（Blighted Ruins）第 3 层。
