## 二、问题统计

| 类别 | 条数 | 编号 |
|------|------|------|
| mistranslation | 1 | r4-ds-01 |
| inconsistent | 1 | r4-ds-04 |
| format | 3 | r4-ds-02、r4-ds-03、r4-ds-05 |
| awkward | 0 | — |
| untranslated | 0 | — |
| runtime | 0 | — |

严重度：全部为 minor（没有阻断性、没有 Lua 报错、没有占位符/颜色码泄露）。

明细见 `findings.jsonl`，摘要：

1. **r4-ds-01** 简单难度说明「不能完成游戏成就。」← “Achievements are not granted.”（应为「不会获得」）。
2. **r4-ds-02** 开场剧情首行「欢迎你 Alder ！」——中文与名字、名字与「！」之间各多一个半角空格，且缺逗号。
3. **r4-ds-03**「技能 震慑打击 已经可以使用。」——技能名两侧多空格；同一句英文在 engine.lua/mod-tome.lua 有两套译文（「已经可以使用。」/「已经可以使用了。」）。
4. **r4-ds-04** 物品说明「命中加成：+0.4% 暴击伤害（最大40%）」与面板「暴击倍率」同词异译，且「暴击伤害」与 crit mult 语义不同。
5. **r4-ds-05** 人物/怪物提示框「命中值 ： 22　闪避值 ： 2」冒号前仍有全角空格——**第三轮 r3-sonnet-01 已修复项的修复未生效**。

### 已核实但未计入 findings 的观察（供参考）

- 战斗伤害日志「Alder击中森林巨魔造成30 物理伤害。」：数字与「物理」之间带空格、句中没有逗号/「点」。属全库统一写法（mod-tome.lua:497/499），暂按风格处理，不计为缺陷。
- 「未命中」用于 miss（「Alder未命中狼。」），可读但偏术语化；「击杀了」「击中了」混用完成体与未完成体（同一条日志模板），未达缺陷门槛。
- 「铁剑」= iron longsword（子类型「长剑」），与「铁质大剑」的材料词写法不统一（铁 vs 铁质），未达缺陷门槛。
- 巨魔沼泽(1) 地图上有大片纯黑未探索区块、玩家不居中，属 GPU 渲染/视野表现，与文字无关。

## 四、环境发现（对后续轮次很重要）

当前加载的汉化插件是 `game/addons/tome-chn-mod.teaa`，**生成时间 2026-11-04 11:21**，而第三轮修复提交是 13:44（`0191ed479 maintenance: lite batch 0329 live-test round 3 fixes (7)`）。核对 .teaa 内的 `data/locales/zh_hans.lua`：

- 其中没有 r3 修复后的 `#FFD700#命中值#FFFFFF#：`、`cooled/被冻僵` 等条目；运行时会回落到 `modules/tome-1.7.6.team` 内置的旧译文（`命中值　#FFFFFF#：`、`被冷藏`）。
- 这与实机所见一致（r4-ds-05 即为现场证据）。
- 因此**本轮游戏内看到的文字并非「含截至今天全部修复」的版本**；凡第三轮已修复项若再现，只能判为「修复未生效」，本轮未把它们重复计入新缺陷。

建议：从当前工作树重新构建 `tome-chn-mod.teaa` 后再开第五轮，否则第三轮的 7 项修复无法在实机中验证。
