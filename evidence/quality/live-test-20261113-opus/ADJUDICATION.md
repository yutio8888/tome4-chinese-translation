# Opus 实机补测（2026-11-13）：结果与裁决

- **性质**：发布后的质量检查，不是发布前置条件，也不等于自然通关。
- **基线**：公开发布的 v0.3.12，`tome-chn-mod.teaa` sha256 `22706f10…`；官方 1.7.6，加 ashes-urhrok、cults、orcs 三个 DLC（各包 sha256 与 `../live-test-20261112-late/dispatch.json` 相同）。共享安装只读，没有重复下载，也没有使用候选包。
- **模型**：只用 Opus。profile「Contextual Reviewer — Opus 5.5」（这是唯一的 Opus profile），即 `claude/claude-opus-5-5`，mode auto，thinking medium，fast_mode 关闭。本轮没有用 DeepSeek 操作游戏。各会话的 agent ID 与会话 ID 见 `dispatch.json`。
- **预算**：每会话读图 20 张（全屏 3 张）、工具调用 100 次、图片 15 MB 收尾 / 20 MB 停止，读图 16 张或调用 80 次开始收尾。这是操作预算，不是自动硬限流。主代理用会话文件做只读统计（`session-stats.txt`，同一工具调用 ID 和同一张图只计一次），另有后台观察脚本，阈值为 90 次调用或 14 MB，本轮没有触发。

## 未覆盖与限制

- **沃尔部落**：施加到玩家身上的效果提示（只有日志）；兽人主题或唯一装备（只生成了随机词缀装备）。
- **天灾之穴**：madness 树后两条技能；利牙项环没有可比较的已装备项链。
- **巅峰**：埃兰达其余技能、uruivellas；首领角色面板只核对了技能页。
- **烟雾宫殿**：托马克其余技能和攻击/防御页；配件制造界面。
- 所有结果都是「调试到场或生成后在真实界面实测」，没有自然取得的结果。控制台只用于定位、放置、生成和打开界面。
- **操作教训**（已写入 `~/tome-live/prompts/HOST.md`）：
  - 新 HOME 第一次启动会弹联网欢迎框，用 `boot.sh` 自动点掉并读档；
  - 控制台的像素校验点用 (10,600)，已打开时不要再按 ctrl+l；
  - 窗口会失焦，用 `focus.sh` 重新聚焦；
  - 有提示框时按 Escape 会打开游戏菜单；
  - `i` 键与 triggerVirtual 经常打不开物品栏，用 `ShowEquipInven` 或 `showEquipInven`；角色面板与升级窗口用控制台 registerDialog 打开；
  - 复制辅助脚本时，脚本里所有显示号都要替换（本轮 o7a2/o7b2 的 dbgopen.sh 截图仍指向旧显示，属主代理失误，o7b2 发现后没有使用）。
