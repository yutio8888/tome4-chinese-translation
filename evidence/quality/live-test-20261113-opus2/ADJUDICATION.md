# Opus 实机测试第二轮补测（2026-11-13）：结果与裁决

- **性质**：维护者明确要求的本地代理测试，属于发布后的质量检查。它不是发布前置条件，也不等于自然通关。
- **基线**：公开发布的 v0.3.12，`tome-chn-mod.teaa` sha256 `22706f10…`；官方 1.7.6，加 ashes-urhrok、cults、orcs 三个 DLC（各包 sha256 与 `../live-test-20261112-late/dispatch.json` 相同）。共享安装只读。本轮**没有使用候选包**，所以全部计数都属于公开版的新覆盖，没有候选回归计数。
- **模型**：只用 Opus。重新读取了 profile「Contextual Reviewer — Opus 5.5」，没有变化：`claude/claude-opus-5-5`，mode auto，thinking medium，fast_mode 关闭。agent ID 与会话 ID 见 `dispatch.json`。
- **预算**：每会话读图 20 张（全屏 3 张）、工具调用 100 次、图片 15 MB 收尾 / 20 MB 停止，读图 16 张或调用 80 次开始收尾。这是操作预算，不是自动硬限流。主代理用会话文件做只读统计（`session-stats.txt`），后台观察脚本没有触发。

## 准备（主代理）

- 复用上一轮 4 份存档：巅峰、沃尔部落、天灾之穴 3 份来自主代理备档的 Astajed，烟雾宫殿 1 份来自 o6b4。game.teag 都在，大小与读档核对时一致。
- 每个测试员显示上，主代理都从干净启动跑过 `boot.sh`（自动点掉联网欢迎框并读档）和本轮新写的 `setup.sh`（用控制台做调试准备），核对了 S8 输出与 Lua Error 0，派发前已结束这些测试游戏。
- 准备期间修正了三处工具问题：
  - 控制台历史变长后，(10,600) 会落在文字上，像素校验误判，已改为同时判断左边框；
  - unique 首领只能生成一次，失败重试时改为先找回已生成的个体；
  - findFreeGrid 可能返回 nil，改为逐格搜索空地。

## 发现裁决

| id | 裁决 | 依据与处置 |
| --- | --- | --- |
| o8d-01：配件制造界面「状态」列中「可制作材质等级(%s)」被截断 | **confirmed**（format） | `tome-orcs.lua:8213`；Orcs `overload/mod/dialogs/CreateTinker.lua:270` 用 `("create tier( %s )"):tformat(upto)` 填入宽度 20% 的状态列。截图显示未选中行被截成「可制作材质等§」，看不到等级数字。已缩短为「可制作 %s 级」，与同列的「条件不足」宽度相近。**0503 修复**（`4326a6ece`）。0504 盲审：A ISSUE 0；B 建议去掉占位符两侧空格（可制作%s级），按本库数值占位符与汉字之间保留半角空格的惯例（如「%d 点」）驳回（`b5db4f11b`）。修改后没有在游戏中复测，因为共享安装仍是公开 0.3.12 包。 |
| 电击除颤器说明：英文「dazing for 2 turns」，译文「眩晕 3 回合」 | advisory（上游原文与实现不符） | Orcs 的 timed_effects/physical.lua:1171 用 `LIGHTNING_DAZE` 且 `daze=100`，没有传 daze_duration。核心 damage_types.lua:1567（624a67329fe2）的默认值是 `dam.daze_duration or 3`，所以实际眩晕 3 回合。按「原文与实现不符时按实现翻译」的裁决，译文正确，不改。 |
| 资源栏提示「幅度最多为 混沌度%」 | 不报 | 照英文 "up to chaotic%" 直译，上一轮 o7b 已核对用词一致。 |
| 水晶球「它可以用于使用水晶球。」 | 不报 | 上游原文 "It can be used to use the orb." 本身冗余，译文忠实。 |
| 冰雪风暴同段「冰冻」与「冻结率」混用 | 不报（风格） | 测试员自己标为风格观察，没有机制错误。 |
| 怪物面板类型/子类为空；防御页空标题；无尽灾厄「（冷却时间）」后无列表 | 不成立 | 均为上游显示逻辑（CharacterSheet.lua:619/622 等），英文版同样如此。 |
| 引擎折行（「40\n% 酸性」等）、「普 通」字间空隙 | 不报 | 已知的引擎排版类别。 |

## 未覆盖与限制

- 托马克技能页另外 2 条技能（技能页布局已截图，未悬停读取）。
- 艾格尼尔的攻击/防御页；沃尔的属性、抗性、装备页及其余技能。
- 半神效果图标；水晶球的激活使用界面；其余配方的说明。
- 所有结果都是调试到场、调试放置或生成后在真实界面查看，没有自然取得的结果。控制台只用于准备、定位和打开界面，不算显示验收。
- 主代理失误：o8a 的 prompt 把 Argoniel 写成「阿尔格尼尔」，本库实际译名是「艾格尼尔」（mod-tome.lua:37994）。测试员按本库名称核对，没有造成误报。
