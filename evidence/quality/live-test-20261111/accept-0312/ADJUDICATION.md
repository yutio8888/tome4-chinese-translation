## 发现裁决

| id | 裁决 | 理由 |
| --- | --- | --- |
| dk1-01 Play! 两种译法 | advisory | `mod-tome.lua:41117`（Birther.lua 中的「游玩！」）和 `:42364`（WandererSeed.lua 中的「开始游戏！」）属于不同对话框，不是同一个按钮。「游玩！」也不是误译。 |
| dk1-02 / dk2-01 模组选择页简介是英文 | advisory（已知边界） | 模组元数据 `init.lua` 的 long_name 和 description 是裸字符串，在插件接管之前就已显示。这属于 11-04 定为暂不处理的「启动/模组菜单官方旧译」一类。如果要用插件代码覆写，属于新的改进项，需要另行授权。 |
| dk3-01 Clork 半岛译作「克拉克」 | pending | 这是纯名称音译问题，`tome-orcs.lua` 中有 16 处，术语库里没有 Clork 条目。按惯例，纯名称问题交给 Gemini 4 Argon 判断；而且需要跨文件改名，要先取得授权。本轮不改。 |
| dk3-02 狂战士职业说明语句 | advisory | 属于二级语感问题（「他的敌人」等），没有机制或忠实度错误。 |

没有 confirmed 的缺陷，也没有阻塞级问题。
