## 故障与自造错误（不是插件缺陷）
1. `ctrl+l` 控制台：窗口需先 `xdotool windowfocus`；打开后必须先点入输入框；每条命令在约 80 字符内可靠，长命令静默失败；**首条命令常被吞掉**（需先发一条 warm-up）。
2. 控制台环境里 `require("mod.class.Object")`、`package.loaded["mod.class.Object"]`、`mod.class.Object` 均为 nil，无法用 `loadList` 载入 kaltor-shop 的对象表，因此无法造出 `PRESSURE_COMBAT_SUIT`。
3. 我在控制台执行 `game:changeLevel(1,"kaltor-shop")` 后游戏进入 `Lua Error: /mod/class/Game.lua:541: attempt to index field 'level' (a nil value)` 循环、画面全黑，只能 `kill -9` 重启（这是我用控制台换区造成的，与插件无关；重启后的 game.log 已重新计数，`grep -a -c "Lua Error"` = 0）。
4. 控制台里 `_t("otber")` / `_t("[leave]")` / `_t("parasitic","effect subtype")` 均原样返回英文，而界面本身是中文——说明控制台的 locale 上下文与渲染时不同，**不能据此判定翻译失效**，故未记为 finding。
5. Esc 会先打开游戏主菜单，导致随后的 ctrl+a（调试菜单）无效；调试列表按键选择也未生效。
