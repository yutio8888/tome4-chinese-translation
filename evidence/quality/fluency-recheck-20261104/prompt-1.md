# ToME4 汉化：中文通顺度审核（lane 1）

请审核一批游戏译文的中文表达是否通顺。输入文件（只读）：/tmp/fluency/input-1.json。
每条有 source（英文，仅帮助理解语境）、target（译文模板）、rendered（把占位符代入示例值后的句子：%d→12、%0.1f→3.5、%s→「火焰」、%%→%；示例值不代表真实内容）。
本次只审中文表达本身，不审译文与英文的意义对应、数值或游戏机制。

## 审核标准（严格）
按玩家在游戏里读到的样子（rendered）逐句通读。以下情况必须判 ISSUE，不得当作风格偏好放过：
- 语序错误：成分错位，宾语、状语或修饰语放错位置。（自拟示例：「对敌人每次都造成你一点伤害」）
- 病句：成分残缺或多余、搭配不当、句式杂糅、主谓宾不完整、指代不清、前后分句接不上。
- 占位符两侧多余的空格把中文词组断开，读起来不连贯。（数字与单位之间的空格可保留。）
以下不判 ISSUE：纯用词偏好、同样通顺的另一种说法。

## 建议译文要求
- 给出整条完整的建议 target（不是片段），意思与原 target 一致，只修语序、语病和断开的空格。
- 占位符（%d、%s、%0.2f、%%等）的个数、种类和先后顺序必须与原 target 完全相同；颜色码（#RED# 等）与 #{bold}# 等标记原样保留；换行数量和位置不变；行首制表符原样保留。
- 不改专有名词与术语。

## 纪律
只读，不修改任何文件，不运行游戏；只允许写 /tmp/fluency/result-1.json。

## 输出
把 JSON 写到 /tmp/fluency/result-1.json（文件里只有 JSON）：
{"lane":"1","verdicts":[{"n":1,"unit_id":"…","verdict":"OK"},{"n":2,"unit_id":"…","verdict":"ISSUE","problem":"指出错位或病句的具体成分","suggestion":"完整建议 target"}]}
每条输入恰好一条 verdict，n 与输入一致。最终回复只写一行：`FLUENCY 1: N verdicts, ISSUE k`
